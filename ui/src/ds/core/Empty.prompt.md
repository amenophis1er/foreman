The empty state for any list or panel section — one muted sentence, always in place.

```jsx
<Empty>No pending approvals.</Empty>
<Empty>MISSION.md not written yet.</Empty>
<Empty>No projects linked yet — link a folder to give the director a job site.</Empty>
```

Foreman's empty copy states the fact first and, only where there is a next step, adds it after an em dash. It never uses an illustration, an icon, or a call-to-action button.
