A unified diff rendered line by line. Only the first character decides the tint — `+` on the add wash, `-` on the delete wash — and `@@`, `diff`, `index`, `---`, `+++` headers step back to secondary ink. Mono, `pre` whitespace, horizontal scroll inside the block so the page never scrolls sideways. When the server truncated the diff, a last line says so and where the rest is. Shown inside `ArtifactViewer` for a changed file; never inline in a rail.
